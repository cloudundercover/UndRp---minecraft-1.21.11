# UndRp---minecraft-1.21.11
UndRp - Paper-плагин для Minecraft 1.21.11, добавляющий PlaceholderAPI-плейсхолдер %undrp_info_&lt;N>%, который показывает установлен ли у игрока серверный ресурс-пак. Отслеживает PlayerResourcePackStatusEvent, хранит статус каждого игрока и поддерживает произвольное число настраиваемых текстовых модулей в config.yml.
